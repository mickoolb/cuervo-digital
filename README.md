## 🤖 Sistema de prospección (cron diario)

Tenemos un **agente automático** configurado que busca clientes potenciales:

- **Horario:** Lunes a viernes 10:00 AM
- **Busca:** Negocios chilenos sin web o con web mala
- **Guarda resultados en:** `leads/leads-AAAA-MM-DD.md`
- **Skills usados:** `web-scraping-tools`

⚠️ **Importante:** El agente solo INVESTIGA. No contacta a nadie. Tú revisas los leads y decides a quién contactar.

## 📋 Plantilla de propuesta

Archivo: `plantilla-propuesta.md`

Cuando tengas un lead, usa esta plantilla para armar la cotización. Está en markdown — puedes copiarla, llenar los datos y enviarla.

## 🛠 Cómo actualizar la página web

1. Edita `index.html` en `~/Desktop/cuervo-digital/`
2. Haz commit y push:
   ```bash
   cd ~/Desktop/cuervo-digital
   git add -A
   git commit -m "descripción del cambio"
   git push
   ```
3. GitHub Pages se actualiza solo en ~2 minutos
